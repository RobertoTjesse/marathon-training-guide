# 26.2 — The Marathon Training Guide

A complete, citation-backed guide to marathon training, published as a static site on GitHub Pages.

Live: **https://robertotjesse.github.io/marathon-training-guide/**

## What's inside

- **Training** — beginner / intermediate / advanced weekly-mileage and long-run targets, the four key workouts, and a sample week.
- **Pacing** — even / negative-split race strategy and the most common pacing mistakes.
- **Nutrition** — carb-loading, mid-race fueling and sodium, and post-race recovery nutrition.
- **Gear** — shoe selection, clothing and a race-day checklist.
- **Injury prevention** — the 10% rule, strength training, and the most common overuse injuries.
- **Taper & race week** — a three-week volume cutdown table.
- **Recovery** — a week-by-week "reverse taper" back to training.
- **Pace calculator** — interactive tool that converts a goal finish time into per-mile / per-km pace plus rough training-pace targets.

## Structure

- `index.html` — the entire site (semantic HTML, embedded CSS and vanilla JS, no build step or framework).
- `README.md` — this file.

## Run locally

Open `index.html` directly in a browser, or serve it:

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

## Deployment

The site is served from the `main` branch via GitHub Pages (project site). Any push to `main` updates it.
